# Kadr TV / Кадр TV

A personal, non-commercial Android TV / Google TV application for browsing films and TV series, saving favorites.

This repository is the public project information page.Source code and APK releases are not published here.

## Current prototype

- Remote-control-friendly interface for Android TV and Google TV (Android 8.0+).
- Local favorites for individual releases.
- No advertising or analytics SDKs.

## Planned movie and TV cards

TMDB integration is planned, but is not yet implemented or approved. The intended use of the TMDB API is to retrieve movie and TV show titles, original titles, release dates, descriptions, and poster images for display in the application.
TMDB would provide metadata and images only. 

## Data and playback

The project does not host or distribute video files. Current favorites and application settings are stored locally on the device.
